# SQL Server 資料庫命名規則

## 1. 基本原則

- #### 統一命名風格: PascalCase
        範例: Member, MemberName

- #### 命名語言: 英文
        範例: MemberName，避免使用中文

- #### 特殊符號: 避免使用
        範例: 避免 @, #, $, %

- #### 保留字: 避免使用 SQL Server 保留字
        範例: 避免 Order, Group, User, Select

- #### 命名方式: 簡短且具描述性
        範例: CustomerAddress，避免 C_Addr

- #### 資料表: 使用單數名詞
        範例: Member, Product, Order

---

## 2. Database / Table / Column

- #### Database: PascalCase
        範例: TravelDB

- #### Table: PascalCase + 單數名詞
        範例: Member

- #### 關聯表: 表A + 表B
        範例: MemberFavorite, OrderItem

- #### Column: PascalCase
        範例: MemberName

- #### PK: TableName + Id
        範例: MemberId

- #### FK: 與參照的 PK 同名
        範例: MemberId

- #### Boolean: Is / Has / Can + 名稱
        範例: IsActive, HasPaid, CanBook

- #### 日期: XXXDate
        範例: StartDate, OrderDate

- #### 日期時間: XXXAt
        範例: CreatedAt, UpdatedAt

- #### 時間: XXXTime
        範例: OpeningTime, ClosingTime

- #### 經緯度: Latitude / Longitude
        範例: Latitude, Longitude

- #### 金額: PascalCase + DECIMAL
        範例: TotalAmount, UnitPrice

---

## 3. Constraint / Index

- #### Primary Key: PK_TableName
        範例: PK_Member

- #### Foreign Key: FK*子表*主表
        範例: FK_Order_Member

- #### Unique: UQ_TableName_ColumnName
        範例: UQ_Member_Email

- #### Check: CK_TableName_ColumnName
        範例: CK_Member_Age

- #### Default: DF_TableName_ColumnName
        範例: DF_Member_IsActive

- #### Clustered Index: CX_TableName_ColumnName
        範例: CX_Member_MemberId

- #### Non-Clustered Index: IX_TableName_ColumnName
        範例: IX_Member_Email

---

## 4. 其他資料庫物件

- #### Stored Procedure: usp_Action_Object
        範例: usp_GetMember

- #### View: vw_Name
        範例: vw_ActiveMember

- #### Scalar Function: fn_Name
        範例: fn_CalculateTax

- #### Table-Valued Function: tvf_Name
        範例: tvf_GetOrders

- #### Trigger: TR_TableName_Action
        範例: TR_Order_AfterInsert
